      How It Works & Refund Rules

      • Your wallet is charged the moment you buy — this reserves a real, working number for you
      • You have about 20 minutes to receive your SMS/OTP code on that number
      • If a code arrives in time, the sale is final — you keep the code
      • If no code arrives before time runs out, you're refunded automatically — no action needed
      • Want your money back sooner? Tap "Cancel & Refund" any time before a code arrives
      • Once a code has been delivered, that number can no longer be cancelled or refunded
